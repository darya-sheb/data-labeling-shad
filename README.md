# Детекция бабочек на фотографиях

На входе — фотография, на выходе — отдельная рамка для каждой видимой взрослой дневной или ночной бабочки. Если бабочек нет, возвращаем пустой список. На 400 фотографиях командной выборки лучший результат показала **Qwen3-VL-2B-Instruct с уточнённым промптом** — объектный F1@IoU 0,50 **0,8742**, F1@IoU 0,75 **0,7889**.

## Пайплайн

1. **Сбор данных.** Собрали [400 фотографий iNaturalist](data/val_dataset.json) с идентификаторами, ссылками и группами: 191 фото с одной бабочкой, 6 с несколькими, 101 с другими насекомыми и 102 без бабочек из отдельной группы.
2. **Предразметка и первичная фильтрация.** [YOLO-World и Codex](pred_boxing/README.md) предложили рамки. Параллельно [исполнители в Яндекс Заданиях](first_stage_filtration/README.md) отвечали, есть ли на фото бабочка. На проверку отправили 205 кадров, где была рамка модели или хотя бы два из трёх исполнителей отметили бабочку.
3. **Ревью и исправления.** В [двух проектах Яндекс Заданий](bbox_review_pipeline/README.md#пулы-и-интерфейсы-заданий) валидаторы проверяли границы, дубли, лишние рамки и пропуски. Версию оценивали два независимых исполнителя, при расхождении привлекали третьего. Разметчики исправляли замечания, после чего фото проверялось повторно. Допуск, контроли, примеры и расходы описаны в [отчёте по разметке](bbox_review_pipeline/REPORT.md).
4. **Golden set.** В [эталоне](data/golden.jsonl) 400 фото, из них 197 с бабочками и 203 с пустым списком. Всего 218 рамок. Из 203 пустых результатов 195 получены на этапе предварительной фильтрации и отдельное ревью рамок для них не проводилось.
5. **Сравнение и Контест.** На одних и тех же 400 фото оценили Grounding DINO Tiny, OWLv2 Base и Qwen3-VL-2B-Instruct. Проверили удаление дублей у DINO и уточнение промпта у Qwen. Сохранённые запуски двух промптов Qwen выполнены с разными версиями библиотек. По максимальному F1@0,50 выбрали строгий Qwen и подготовили [JSONL для Контеста](model_comparison/results/submission.jsonl) на отдельном наборе из 400 фото.

## Воспроизведение

Установите виртуальное окрудение:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
```

Из корня репозитория соберите golden set из сохранённых голосов и сравните его с опубликованным файлом:

```bash
python bbox_review_pipeline/run.py replay --output golden_replay.jsonl
cmp golden_replay.jsonl data/golden.jsonl
```

[Инструкция по запуску разметки в Яндекс Заданиях](bbox_review_pipeline/how_to_run.md).

Для **нового запуска моделей из фотографий** установите зависимости для CPU или NVIDIA GPU по [инструкции инференса](model_comparison/README.md#новый-инференс-из-фотографий), откройте ноутбук экспериментов, задайте `RERUN_ALL=True` и выполните все ячейки.

Для пересчёта опубликованных метрик на CPU откройте [ноутбук бейзлайнов](model_comparison/notebooks/baseline/models_comparison.ipynb) и [ноутбук экспериментов](model_comparison/notebooks/experiments/experiments.ipynb) с `RERUN_ALL=False`. Пересчитанные таблицы появятся в `runs/tables/`, отчёт — в `runs/RESULTS.md`. Установка зависимостей, повторный инференс на GPU и команды для Контеста описаны в [README сравнения моделей](model_comparison/README.md).
