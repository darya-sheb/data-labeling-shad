# Как запустить проект

Команды выполняются из папки с [run.py](run.py). Нужны Linux или macOS и Python 3.10+. Зависимости входят в стандартную библиотеку. [Карта файлов и правила](README.md) · [Отчёт о завершённом запуске](REPORT.md)

## 1. Воспроизвести готовый результат

```sh
python3 run.py replay
cmp golden.jsonl reference/golden.jsonl
```

Обе команды работают офлайн. Первая собирает 400 строк из входных фотографий и сохранённых голосов. Вторая завершается с кодом 0 при побайтовом совпадении. Для отдельного пути используйте `replay --output ПУТЬ`. [Исходные фото](data/photos.json) · [Финальные версии и голоса](reference/final_votes.jsonl)

## 2. Проверить подготовку нового сбора

```sh
python3 run.py plan
python3 -m unittest discover -s tests -v
```

`plan` создаёт проекты, обучения, пулы и очередь во временной локальной базе. Тесты проверяют повторный запуск, экзамены, независимость голосов, исправления, приёмку и выгрузку.

## 3. Запустить новый платный сбор

Укажите токен заказчика Яндекс Заданий в переменной окружения `OAUTH_TOKEN`. Для запуска нужны интернет и средства на балансе.

```sh
python3 run.py start
```

Команда создаёт два проекта, два обучения, пять пулов и три навыка, загружает задания и интерфейсы, ставит 205 фото в очередь. Пулы проходят модерацию. Пулы исправлений и проверки экзаменационных фото открываются по мере появления работы. Обработчик опрашивает платформу раз в 60 секунд.

`Ctrl+C` останавливает обработчик после текущего цикла. Для продолжения повторите `start` с тем же каталогом `state/`. Если в журнале осталась операция создания в состоянии `PENDING`, сверьте объект в кабинете заказчика перед повторной отправкой.

## 4. Посмотреть ход работы

```sh
python3 run.py status
tail -f state/worker.jsonl
```

| Файл в `state/` | Что смотреть |
|---|---|
| `results.json` | Последняя версия каждого рабочего фото и её статус |
| `pending_validation.json` | Вопросы, для которых ещё нет нужных голосов |
| `exam_acceptance.json`, `validation_exam_acceptance.json` | Баллы и статус оплаты экзаменов |
| `acceptance_queue.json` | Версии, которые можно принять как есть после двух отклонений. Для сверки указаны фото, рамки и номера отклонённых версий |
| `pipeline.sqlite3` | Журнал объектов, сдач и приёмки. Сохраняйте между запусками |

Для приёмки возьмите `acceptance_id` нужной версии из очереди и выполните команду.

```sh
python3 run.py accept ACCEPTANCE_ID
```

Обработчик учтёт решение в следующем цикле. Уже выданное исправление должно завершиться. Пустое фото закрывается двумя независимыми голосами.

## 5. Получить датасет

Когда готовы все отобранные фото, обработчик записывает `state/golden.jsonl`. Повторная выгрузка — `python3 run.py export`. В файле одна строка на каждое входное фото. Координаты задаются в долях ширины и высоты.

```jsonl
{"photo_id":123,"boxes":[{"left":0.10,"top":0.20,"width":0.30,"height":0.40}]}
{"photo_id":124,"boxes":[]}
```
